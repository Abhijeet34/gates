# Decision request: drop the separate security review seat

## Recommendation

Drop the separate security review seat to save review time.
It adds 3.0 minutes to each of 300 reviews a month, 900 minutes in all.
Its findings were upheld 4 times in those 300 reviews, about 1.3%.
Those 4 were the month's two credential leaks and two authentication bypasses, which no other seat caught, so the seat stays on sensitive paths and is dropped only on the rest.

## Evidence

- Reviews last month: 300; the security seat added a mean 3.0 minutes to each.
- Security seat findings upheld last month: 4.
- Those 4 were the only two credential leaks and two authentication bypasses caught last month; no other seat reported them.
